# Куда выкладывается боевой сайт

Боевой Worker `bazar-demo` (https://bazar-demo.xugushik.workers.dev) собирается и выкладывается **только из этого репозитория** (`xugushik-source/bazar-demo`, ветка `main`) через Cloudflare Workers Builds.

Репозиторий `xugushik-source/bazar` (ветка `feature/bazar-store`, workflow «Сервер Базара») указывает на тот же Worker и ту же базу D1, но содержит другую линию кода. Его выкладка 21.11.2026 заменила боевой сайт старым кодом (пропали недавние доработки, вернулись часы приёма заказов). Этот репозиторий был выложен заново 22.11.2026.

Правило: пока линии не объединены, не запускать workflow «Сервер Базара» в `xugushik-source/bazar`.
